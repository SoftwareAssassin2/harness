- Security: authentication, permissions, secrets, user input
- Blast radius: shared code, public APIs, infrastructure, configuration
- Confidence: how well the change is covered by tests

Write the assessment to {ticket-folder}/risk-assessment-{variation}.md (through `{agent-sh} work:write {project} {ticket} {variation} risk-assessment.md`, the whole file on stdin).

Finish with JSON: {"flagged-for-human-review": true} if a human should approve this before it merges, otherwise {"flagged-for-human-review": false}.
