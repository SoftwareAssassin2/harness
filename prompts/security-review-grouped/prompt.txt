When the variation is built in a worktree and your review finds risk only a full machine can check, escalate it (Work mode, above) with review, say why in your findings, and reject the change: it is built again on a full machine.

The changes are in every merge request not Closed: {agent-sh} ticket:merge-request-plan {project} {ticket} {variation} lists each one's id, repository, branch and base. Review them all in one pass: in each one's repository checkout, git fetch origin, then its changes are git diff origin/<base>...origin/<branch>.

Look for:
- Injection (SQL, shell, template) and unvalidated input
- Broken authentication or missing permission checks
- Secrets or credentials in code, config or logs
- Sensitive data exposed in responses, logs or errors
- New dependencies with known vulnerabilities

The workflow runs none of the project's CI checks (secret scans, policy gates) itself: the project's own CI pipeline runs them on the merge request. So look for what they would catch in the diff yourself: a secret, a credential or a policy breach in the change is a finding. Never copy a secret value into security-review-{variation}.md or anywhere else: name its merge request, file, line and kind only.

If {ticket-folder}/operator-review-{variation}.md exists, it holds the operator's notes from rejecting earlier passes at Human Review: read it and address each note in this step's work.

Write your findings to {ticket-folder}/security-review-{variation}.md (through `{agent-sh} work:write {project} {ticket} {variation} security-review.md`, the whole file on stdin), most severe first; each finding names its merge request, file and line.

Finish with one verdict for them all, as JSON: {"is-approved": true} if nothing must be fixed first, or {"is-approved": false} if security-review-{variation}.md lists something that must.

A golden-image rebuild ticket ("fast-track": true in {ticket-folder}/ticket.json, titled "Rebuild golden-<project>") has no merge request and changes no code: there is nothing to review: {"is-approved": true}.
